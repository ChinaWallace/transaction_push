# 当前模拟规则：优选长期仓 + 普通轮动仓

2026-09-25 起适用。优选默认 ZECUSDT、BTCUSDT、ETHUSDT；均为 USDT 永续模拟，不是现货账户。

| 规则 | 优选长期仓 | 普通策略仓 |
|---|---|---|
| 方向 | 只做多 | 只做多 |
| 杠杆 | 当前执行1x；已授权2x并单独回测，70%预算口径待用户确定 | 根据波动、历史、市值限制，最多 3x |
| 单币名义仓位 / 账户权益 | 固定25%限制已取消；可设置，当前新买入上限70% | 最多 10% |
| 优选合计 | 新买入检查合计70%；上涨后允许权重漂移，默认三币初始目标仍各约23.33% | 使用剩余保证金额度 |
| 单币止损 | 默认关闭；可选入场均价下方 35% 固定宽止损 | 2.5 倍 1h ATR 初始止损、3 倍 ATR 追踪 |
| 1h/15m 信号、排名、72h 退出 | 豁免 | 保留 |
| 账户 45% 回撤触发 | 不退出、不因该熔断暂停优选入场 | 清仓，暂停普通仓 28 天 |
| 长期持有后 | 允许浮盈自然增长，不因超权重机械减仓；自动加仓先按v8研究对照 | 按各周期目标执行 |

候选池与同时持仓上限均为 50，不要求满仓或买满 50 个。趋势、成交量、市值、费用、相关性、信号和风险预算仍可能使实际持仓远少于 50 个。优选优先进入候选池，但必须通过真实数据和入场条件；不会因手动添加而直接无条件买入。估值缺失仍将优选单币限制在 15%。

当前总保证金上限 85%（原 65% 在优选总额度超过 50% 后等额增加，最高 85%），总名义敞口仍不超过 180%。普通仓计划止损风险最多 25%，单币 2.5%；这个止损风险数字不涵盖无止损优选仓。优选与普通仓都计手续费、滑点和真实资金费。账户整体**没有 50% 最大回撤约束**，可能超过该水平；1x 永续也存在资金费和强平风险。本模拟尚未精确重建交易所的强平价格、历史保证金阶梯与订单簿深度。

## 操作与配置

在看板“优选与仓位”输入 `ZEC,BTC,ETH`，或从候选表“填入优选”，再保存模拟规则。支持候选/持仓上限、优选单币限额、上涨权重漂移，以及无止损/宽止损切换。只允许当前合约目录中的代码，同名代码自动转为 USDT 合约并去重。

服务配置和默认交易规则来自项目 `.env`。手动编辑的交易偏好存储于配置输出目录的 `portfolio_policy.json`；它是持久化用户状态，覆盖相应 `.env` 默认值，不包含任何密钥。保存带版本校验，下一次有效模拟周期应用。撤销优选属于保护性变更，即使费用数据暂时不完整，也恢复普通仓保护。已有 2x/3x 普通仓转优选时，先明确记录模拟退出，再按新入场条件建立 1x 仓，不篡改旧成交。

```bash
./scripts/quant.sh start        # 采集 + 模拟 + 看板
./scripts/quant.sh status
./scripts/quant.sh restart      # 保留账户、历史和优选
./scripts/quant.sh config
./scripts/quant.sh permissions  # 只读检查本机密钥，不创建测试/真实订单
./scripts/quant.sh test
./scripts/quant.sh compare      # 四币同样本方案对照
```

`QUANT_EXECUTION_MODE` 只能是 `paper`，设成 `live` 会被配置验证拒绝。quant 运行路径没有交易所下单适配器。权限核验与公开行情分离，采集不使用密钥。

2026-09-25 本机只读核验：Wallet API 权限接口 HTTP 400 / -2015；USD-M 合约账户接口 HTTP 401 / -2015。结论为“权限未知/当前鉴权被拒绝”，不能断言密钥只读。-2015 可能涉及密钥、IP 或操作权限，参见 [币安说明](https://www.binance.com/en/academy/articles/understanding-the-binance-invalid-api-key-2015-error)。检查未修改账户权限，未发送订单；不能据此保证机器上所有其他客户端都无交易能力。

## 策略研究与验证边界

当前方案不是已经证明的最佳策略，也没有可承诺的未来收益。先把可检验的组合规则落地，再使用同条件基准筛选策略。

- [bittrends 原始研究代码](https://github.com/Globe-Research/bittrends)与[论文](https://arxiv.org/abs/2009.12155)：趋势/突破方向可作为简洁基准；早期 BTC 样本不能代表今天全池。
- [NostalgiaForInfinity](https://github.com/iterativv/NostalgiaForInfinity)：公开 Freqtrade 策略，原生主周期 5m，适合独立对照。已在v5固定上游版本并实际对照X7/X8；GitHub热度和作者回测不证明优于本方案，结果见三币研究报告。
- [6h 趋势多空研究](https://arxiv.org/abs/2602.11708)：属于预印本作者报告，尚未独立复现；没有据此开启做空。
- [Freqtrade 前视偏差检查](https://www.freqtrade.io/en/stable/lookahead-analysis/)及[杠杆说明](https://docs.freqtrade.io/en/latest/leverage/)作为后续外部策略验收依据。

四币样本为 BTC/ETH/ZEC/UNI，6,560 根已收盘 K 线和 124 笔真实资金费；逐文件来源/哈希在 `reports/quant_v4/policy_sample/manifest.json`。扣除指标预热后的共同回放区间：2026-09-15 05:45 至 2026-09-24 15:44:59 UTC。

同一数据、成本和撮合器的集成对照：原轮动净变动约 +3.18%，新优选方案 +7.73%，新方案双倍成本 +7.43%；采样收盘回撤分别约 3.36%、3.68%、3.69%。原轮动对照采用当前 50 仓上限。结果文件 `reports/quant_v4/policy_comparison.json` 保留具体模拟成交、信号、费用和权益曲线。

这仅是约 9 天的集成测试，**不是收益验证或最优策略排名**。历史市值缺失使每个优选目标上限为 15%，不能证明当前 70% 优选额度的风险；15m OHLC 无法还原逐笔先后和真实强平。未据此调参选赢家。正式策略比较仍需历史上市/退市币池、较长历史、固定参数后时间留出、成本翻倍、剔除 ZEC、资金费与强平压力，以及持续前向验证；旧版日线回测结果不适用于当前策略。
