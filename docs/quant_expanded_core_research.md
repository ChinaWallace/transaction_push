# 三币底仓与16币扩展比较 v12

2026-09-26。本轮比较的研究首选是 **TriEnhance：BTC / ETH / ZEC长期底仓＋40%慢退出增强**。新增13币进入独立研究池，尚无证据支持把它们全部买成长持底仓。这里的首选限定于冻结的候选、历史窗口和成本条件，不代表全市场最优或未来保证。

研究共42组，使用同一10,000 USDT初始资金、同一成交/标记行情与真实资金费。看板 `/api/quant/dashboard#holding-research` 默认展示v12，点击方案查看底仓与增强成交、费用、月度收益和风险。仅公开数据与模拟资金；旧全池及v6账户仍停止，没有替换执行策略。

## 首选方案的具体规则

- 底仓：BTC、ETH、ZEC各约初始权益23.33%，合计约70%**名义金额**，数量按公开合约步长向下取整。三币共享一个全仓钱包，最高2x设置；不等于初始140%敞口。研究按各窗口首日04:00 UTC成交，只在样本结束结算。
- 底仓长期保留：不按72小时、25%权重、短线信号或45%熔断卖出；上涨后不机械压回权重。长期持有不保证回本。
- 增强入场：已完成4h收盘突破之前20根高点，收盘高于EMA50且EMA50高于EMA200，同时原底仓盈利；多币并发按过去动量排序。信号可得后的5m报价模拟成交。
- 顺势追加：每轮后续加仓需较上次增强买价再涨10%；每笔名义金额最多权益10%，可用额度不超过该币底仓正浮盈2倍减去已有增强名义金额，新增增强总额度不超过权益40%。成交后总敞口不超过权益1.4倍。上涨漂移不因此触发机械减仓。
- 退出增强：连续两根完成4h收盘低于EMA200时退出增强仓，卖出后冷却4小时。总敞口/权益超过1.5时优先退出增强；底仓残余风险不能因此被隐藏，余额下界仍为负会记录并禁止继续加仓。

不亏损摊平；全仓按同币整仓平均成本记账，底仓/增强只是收益归因。同步计入维持保证金分档、资金费、共同下跌压力与全币归零余额下界。单币无正强平价仅在其他币价格不变时成立。

## 数据、会计和修复证据

每币208,224根连续5m成交与标记K线，覆盖2024-10-01至2026-09-24，含每窗口92天统一预热；每币2169个真实资金费事件。公开ZIP与CHECKSUM、REST原始响应、准备后的数据文件均保留，1492个来源/数据文件SHA256通过。13币的2026-06-29标记归档缺口各288根，均用真实公开REST补齐。最初HTTP403及BCH连接失败记录保存在 `data/attempts`，未隐去故障。

冻结前修复了继承的期末时序问题：最后一根5m先计算持仓低点/收盘风险，之后才按收盘价结算，成交标记为收盘时刻；不会在开盘时提前使用未来收盘价把风险清掉。期末结算前的敞口与集中度峰值也保留。收盘权益归于刚结束的月份，资金费仍按实际结算事件归属。人工反例覆盖最后一根69.3%压力回撤，旧逻辑会误报0%，新逻辑会排除。

v11原报告与源码作为历史实验保留、不覆写。本轮三币控制统一使用新数量过滤、92天预热及修复后的时序，与v11数值略有不同；优先看本轮同引擎配对结果，不能把改动混成策略收益提升。运行失败会保存failed状态；损坏缓存、改过的协议或数据不能被静默复用。

## 验证边界与下一阶段

当前币名单有事后选择及幸存偏差，重复历史窗口不是独立样本外。期初固定买入的底仓对入场日期敏感；本轮不是证明在2025前已能挑中ZEC。全仓使用静态维持保证金分档、当前下单过滤和5m共同低点近似，未模拟真实盘口队列、强平罚金、普通仓混合抵押风险。历史回撤低于50%不保证未来最大损失低于50%。

因此，本轮保留三币增强为研究首选，50%＋20%组合为较低集中度备选，13新币继续作为有条件研究对象。优先开展冻结规则的新行情独立验证，不在已看过的历史上无限调整参数追逐收益。前向至少30自然日；主动策略至少10笔闭合交易才开始评价，持有基准按共同窗口盯市。现在尚无这份新前向证据，也没有自动开启被用户停止的模拟服务。

70%按名义金额还是保证金仍以之后明确的执行偏好为准，本轮仅研究名义70%，不静默翻倍。旧全池的普通仓风险不能由本轮纯优选组合推断。
