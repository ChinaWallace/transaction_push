## 本轮纠正的问题

ZEC在2026年7月1日04:00 UTC至9月23日23:55 UTC，从401.59升至1499.89，价格上涨273.49%。同一10000 USDT账户以约23.33%初始仓位分别持有BTC/ETH/ZEC，扣费用及实际资金费后收益88.15%，5m标记价回撤9.20%。原三种主动退出策略同段仅11.75%～26.83%。入场和选币不是唯一问题：过早退出、长期空仓、上涨后机械减仓都截断了收益。

v7共63组新回测，并重新对账21组原v6结果。所有期间及成本使用同源数据；相同初始预算不等于相同平均敞口。持有基准通常在窗口首日04:00 UTC首次入场，不能称为00:00入场。引擎在部分内部窗口于结束边界强制平仓并包含该时点资金费，逐笔时间才是权威。

| 1x方案 | 2026年1–9月收益 / 回撤 | 2025全年收益 / 回撤 | 2025双倍成本收益 |
|---|---:|---:|---:|
| 三币等权持有 | 41.72% / 34.80% | 199.46% / 46.49% | 199.14% |
| 1h突破、4h慢退出 A1SlowHold | 66.21% / 16.95% | 232.46% / 33.71% | 214.36% |
| 4h突破、4h慢退出 D55SlowHold | 59.40% / 16.78% | 248.00% / 33.22% | 243.62% |

这两种慢退出保留原入场，在连续两根已完成4h收盘低于各自EMA200时退出，不用ATR追踪和72小时限制。它们在7–9月单边上涨段仍输给持有。`reports/quant_v7/selection.json`将它们列为**事后研究候选**，三币持有为正式基准；不是未经验证地宣布新“最佳策略”。M4慢退出在2025双倍成本时低于持有，未列入这份候选。

前视检查：A1SlowHold、M4SlowHold各检查12个信号，D55SlowHold检查4个，未发现偏差。三个HoldEntry仅期末强制退出，工具有效交易不足，不能标成通过；状态保存在`lookahead_status.json`。单元验证覆盖合并4h时点、未来数据不改变旧信号、现金流和保证金。

## 浮盈加仓 v8

50组回放使用相同的三币初始成交，比较：不减仓、持续压回70%总权重、持续压回70%总/25%单币，以及两档浮盈加仓。

加仓条件固定为：4h已收盘突破之前20根最高价且高于EMA50；成交时价格较上次买入再涨至少20%。允许累计新增投入不超过初始仓当前浮盈的50%或100%，每笔不超过账户权益5%；只花剩余现金，另保留1000 USDT。浮盈只决定额度，**不会凭空增加可用现金**。无亏损摊平，无自动止盈。最小新增名义金额100 USDT，数量步长假设写在协议。

| 方案 | 2026年7–9月收益 / 回撤 | 2026年1–9月收益 / 回撤 | 2025全年收益 / 回撤 |
|---|---:|---:|---:|
| 不减不加 | 88.15% / 9.20% | 41.72% / 34.80% | 199.46% / 46.49% |
| 持续限制单币25% / 合计70% | 67.21% / 7.88% | 25.94% / 33.90% | 84.40% / 33.41% |
| 浮盈50%额度加仓 | 103.54% / 10.77% | 51.97% / 34.80% | 268.64% / 51.73% |
| 浮盈100%额度加仓 | 107.99% / 10.84% | 56.50% / 34.80% | 263.64% / 51.25% |

加仓增加了投入，不能宣传为同风险下白得收益。两档2025回撤略超此前50%研究阈值，暂未据此替换当前全池账户的自动加仓规则。用户新授权优选最高2x，并明确全仓模式，最新全仓对照见v10。

第一次v8回放在资金费边界对账相差0.39277 USDT时主动失败；修复了结束时点资金费与终止平仓的顺序，失败协议、代码和输出保留在`reports/quant_v8/invalidated/endpoint-funding-correction`。最终所有基准与引擎利润误差均在1分以内。

## 逐仓2x历史对照 v9

本组使用逐仓，不能代替用户要求的全仓结果。分别比较70%保证金（约140%名义敞口）与70%名义敞口（约35%保证金），不把两者混在一起。使用Freqtrade自带静态Binance维持保证金档位及强平模型，留10%强平价格缓冲；未取得历史保证金档位，也未计强平罚金。因此不是交易所历史强平的精确复现。官方说明见[Freqtrade杠杆和强平](https://www.freqtrade.io/en/stable/leverage/)。

原始2x持有策略在强平后允许按后续信号重新入场，**不能称为持有穿越回撤**。NoReentry保留每币同一笔初始仓位，一旦退出就永久停止该币买入；它是逐笔现金流重建的反事实对照，单独标识，不计作新的引擎回测。具体收益、回撤、强平次数见`reports/quant_v9/REPORT.md`。

## 全仓2x与灵活加减仓 v10

独立全仓模型已完成40组：5个时间窗 × 4种方案 × 正常/双倍成本。三币共享USDT钱包，按同步5m标记价计算账户权益，维持保证金按当前名义市值分档。账本单独计入实际资金费、实现盈亏和手续费；浮盈可贡献全仓权益，不直接伪造钱包现金。

全仓规则依据[币安强平价与维持保证金公式](https://www.binance.com/en/support/faq/detail/b3c689c1f50a44cabb3a84e663b81d93)。`2x`设置本身不等于账户2倍敞口；相同数量的70%名义仓位组，与1x持有基准利润逐笔对齐。70%保证金组初始数量翻倍，约140%名义敞口，必须单独比较。

灵活组以70%初始保证金起步。当已知5m开盘报价下，总名义市值/账户权益超过1.6，按比例部分减仓到0.9，计入手续费与标记价/成交价差。加仓组额外要求已收盘4h突破前20根高点和EMA50、价格较上次买入涨20%、当前持仓盈利；追加保证金取当前正浮盈50%减去累计已加保证金，每笔至多权益5%，成交后账户敞口至多权益1.4倍。没有单币25%机械减仓、72h期限、普通止损或45%回撤熔断。

| 全仓方案 | 2026年7–9月收益 / 回撤 | 2026年1–9月收益 / 回撤 | 2025全年收益 / 回撤 |
|---|---:|---:|---:|
| 70%名义仓位持有 | 88.15% / 9.20% | 41.72% / 34.80% | 199.46% / 46.49% |
| 70%保证金持有 | 176.30% / 15.29% | 83.43% / 66.57% | 398.92% / 64.89% |
| 风险升高部分减仓 | 176.30% / 15.29% | 31.24% / 55.39% | 204.32% / 55.71% |
| 浮盈加仓＋风险减仓 | 216.66% / 16.91% | 53.48% / 55.39% | 217.58% / 66.66% |

全部40组在静态保证金模型下未触发边界，包括同一5m各币低点同时出现的保守压力检查；这支持“全仓2x配合账户余量并不必然强平”，不等于真实交易所永不强平。灵活方案在完整年份仍超过50%研究回撤容忍，未自动晋级。2025加仓方案增加13笔、风险减仓3轮，收益低于相同初始杠杆的静态持有，说明本轮加減仓时点并不够好；不能只展示夏季216.66%的结果。

“每个币都没有正强平价”仍以其他币价格不变为条件。更强的检查是 `钱包余额 − Σ(持仓数量 × 均价)`：在所有多仓同时归零、尚未扣未来费用时还剩多少。完整2026灵活组一次减仓把有效杠杆从1.60272降至0.9，该余额下界从−3896.44变成+645.95 USDT；减仓前各币的条件强平价也已无正值，说明仅看单币界面不够。后续加仓或资金费会再次改变余额，不能把该数永久锁定。

选择看板中的v10全仓研究，点击方案可看加减仓流水、减仓前后有效杠杆、余额下界和条件强平价。完整账本在 `reports/quant_v10/runs/*/*/events.json`，风险快照在 `risk_snapshots.json`。只用未来5m低点评估压力，不据此在过去开盘成交。若出现模型风险越界，收益标为假设值并失去筛选资格，不编造强平价或强平后复活。

局限：静态档位非账户专属/历史档位；未含其他普通仓或多币种抵押品；按比例减仓尚未取整到真实交易所步长；未模拟网络延迟、拒单、跳空成交和强平罚金。13项全仓算术/因果回放测试通过，全部40组现金流对账通过。参数首次运行前冻结，不能在同一结果目录里边看收益边修改。
